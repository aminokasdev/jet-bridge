# JET Bridge — лендинг (тестовое задание)

Вёрстка по макету Figma (desktop 1440px): HTML + SCSS + TypeScript, сборка на Vite.

## Запуск

```bash
npm install
npm run dev      # dev-сервер http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
npm run preview  # просмотр собранной версии
```

## Структура

```
index.html                 разметка всех секций
src/main.ts                точка входа: шрифты, стили, инициализация модулей
src/ts/menu.ts             выпадающее меню (Esc, клик вне)
src/ts/lang.ts             переключатель RU / KZ (сохраняется в localStorage)
src/ts/slider.ts           слайдер отзывов (стрелки, свайп, клавиатура)
src/ts/reviews.ts          данные и шаблон карточки отзыва
src/ts/form.ts             маска телефона, валидация, отправка формы
src/styles/_variables.scss дизайн-токены: цвета, градиенты, радиусы, брейкпоинты
src/styles/_*.scss         стили по секциям
src/assets/img/            изображения @2x
```

## Pixel perfect

- Все размеры, отступы и позиции сняты с макета 1440px; проверено наложением скриншота на макет.
- Шрифт в макете — Futura PT (коммерческий). В проекте подключён свободный аналог **Jost** (@fontsource),
  межбуквенные интервалы подогнаны под ширину строк макета. Если Futura PT установлена/подключена —
  она используется первой (`$font` в `_variables.scss`).
- Изображения нарезаны из экспорта макета. Для финальной версии замените их экспортом из Figma
  (Export → 2x, те же имена файлов в `src/assets/img/`).
